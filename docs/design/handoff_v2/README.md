## What it built (6 surfaces)
1. **Lock screen** — the push-notification moment: golden-hour gradient, "Great evening to shoot — grab the 35mm. Golden hour hits 8:15 and Sweet Auburn is buzzing. 6 min away." + tagline **"Own the life, not the light."**
2. **Today** — dismissible gear banner · "Your shoot tonight" · inspiration hero (pulsing "Tonight's pick", "perfect for the fast 35mm", chips, "I'm going" + Details, expandable **"Why this pick?"** → Light / Activity / Your kit) · **"Best near you · N tonight"** ranked list.
3. **Spot detail** — 340px hero, back/save, type + light-window chips, "why here", the **light-quality ramp chart** (now-bar ringed), **"What to look for here"** (numbered field notes), **"What people shoot here"** (2-col gallery), "Getting there", sticky "I'm going".
4. **Plan (This week)** — day-grouped cards tagged Light- / Activity- / Event-driven, "I'm going" toggles, "Your plan · N going".
5. **Bag** — gear onboarding: "What's in your bag?", camera (Fujifilm X100VI), lens/focal-length chips, "pick your style" escape hatch, Continue / Skip.
6. **Bottom nav** — Today · Plan · Bag.
